# 專案進度（內部新品・外部設計・企禮客製）

公司各類專案的進度追蹤網站，依專案類型分頁：

- **全部專案**：所有類型放在同一張時間軸與清單，看誰落後、誰快到期，可依類型篩選。
- **內部新品開發**：2026/6 – 2027/9 年度新品計畫（總覽、工作台、甘特圖、產品進度、儀表、Email 提醒、流程規則）。每款新品可在年度階段之外設定自己的時程。
- **外部設計案**：中長期案，預設 6 個階段約 4–5 個月（需求訪談與簽約 → 概念提案 → 設計發展 → 打樣與測試 → 修正定稿 → 量產與交付）。
- **企禮客製案**：短期案，預設 6 個階段約 6 週（需求確認與報價 → 設計提案 → 客戶確認 → 打樣確認 → 生產製作 → 包裝出貨）。

建立外部設計案或企禮客製案時填開始日與客戶交期，各階段會依範本比例排進交期內；未填交期則依範本天數排程。之後可逐階段調整日期、整批平移或依新交期重排，調整會留下紀錄。

網站：https://ystudiotwo-create.github.io/new-product-tracker-2027/

## 架構

- 前端：GitHub Pages 上的靜態檔案，無需建置
  - `index.html`：版面與樣式，含登入畫面
  - `app.js`：頁面邏輯（沿用原 Claude Artifact 版本）
  - `backend.js`：Supabase 登入、資料同步與檔案上傳，提供 `app.js` 使用的 `db` / `user` / `assets` 介面
  - `config.js`：Supabase 專案網址與公開金鑰（anon key 本來就是公開的，權限由資料庫規則控管）
- 後端：Supabase
  - 所有資料存在 `docs` 資料表（collection, id, data），即時同步
  - 專案存在 `products` 集合，以 `type`（internal / external / gift）區分；外部設計案與企禮客製案的階段日期存在 `stages`
  - 檔案存在私人 bucket `files`，以有時效的簽章網址讀取
  - 結構與權限規則見 `supabase/schema.sql`
